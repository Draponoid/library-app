# Область анализа и обоснованные исключения

Дополнение серверного развёртывания: Bandit также проверяет deploy/*.py;
покрытие включает модуль серверного резервирования. В deploy/postgres_backup.py
локально обоснованы B404/B603 для запуска PostgreSQL-инструментов по абсолютным
путям, списками аргументов без shell. Пароль передаётся только через окружение.
Проверка B608 локально подавлена для SQL контрольных сумм: имена таблиц выбираются
исключительно из фиксированного TABLES, пользовательские идентификаторы в SQL
не вставляются. Ни одно правило не отключено глобально.

Bandit проверяет app.py, database.py, setup_local.py, scripts/*.py и deploy/*.py со всеми
штатными правилами и всеми уровнями серьёзности/уверенности. Глобальных skips,
baseline и исключённых правил нет. Ruff проверяет Python-код, включая тесты;
форматирование проверяется отдельно, изменять файлы во время verify запрещено.

Локальные исключения Bandit:

| Правило | Место | Обоснование и контроль |
|---|---|---|
| B404 | import subprocess в setup_local.py, scripts/checks.py, scripts/mutation_check.py | Запуск локальных инструментов необходим для установки и автоматических проверок. Сам импорт не запускает команду. |
| B603 | subprocess.run в тех же файлах | Используются списки аргументов без shell; Python берётся из sys.executable или абсолютного пути .venv, Node разрешается через shutil.which. Команды и тестовые селекторы заданы исходниками. Данные HTTP-запросов, пароли и пользовательские SQL в команды не попадают. Ошибки дают ненулевой статус, результаты проверяются. |
| B404 / B603 | deploy/postgres_backup.py | Фиксированные PostgreSQL-инструменты запускаются по абсолютному пути, без shell, списками аргументов. Пароли передаются через окружение. Ошибки не выводят секреты. |
| B608 | deploy/postgres_backup.py, SQL контрольных сумм | Имена таблиц берутся исключительно из константы TABLES; входные данные пользователя не подставляются в SQL. |

Обоснование находится также возле каждой пометки `nosec`. При изменении источника
команды, добавлении shell=True или внешних аргументов исключение пересматривается.
scripts/checks.py проверяет наличие объяснения для каждой такой пометки.

Динамические SQL-запросы справочников приложения заменены набором статических
запросов. Единственное обоснованное исключение B608 относится к серверной проверке
копии, указанной выше. Тесты не входят в Bandit-скан приложения:
assert, тестовые пароли и намеренно ошибочные данные являются частью проверок.
Они проходят Ruff и pytest. Покрытие измеряется для app, database, setup_local
и deploy, ветви включены, общий порог остаётся 80%. Инфраструктурные скрипты
дополнительно проверяются поведенческими тестами политики и самим make verify.
