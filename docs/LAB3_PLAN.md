# План лабораторной работы №3

Цель: воспроизводимая установка и проверка «Библиотеки», версионирование схемы,
восстановление данных и функциональное изменение через полный `make verify`.

Архитектура: существующие Flask и sqlite3 сохраняются. Yoyo управляет тремя
миграциями: исходные таблицы, индексы, счётчик продлений. Резервирование использует
SQLite backup API. Восстановление создаёт новый файл после проверки копии.
Новая функция: библиотекарь один раз продлевает действующую непросроченную выдачу
на LOAN_DAYS от прежнего срока, операция атомарна с аудитом.

Ограничения: сохранить существующие данные, не изменять рабочую БД при проверках,
не пропускать тесты, покрытие строк и ветвей не менее 80%, функциональные требования
ТЗ покрыты минимум на 40%, все отклонения анализаторов обоснованы.

## Особое внимание

Существующая БД без истории миграций должна обновляться без повторной загрузки демо.
Повреждённая копия не должна создавать файл восстановления. Существующий файл
назначения никогда не перезаписывается. Одновременные продления допускают ровно
один успех. Дата due_at, равная сегодняшней, ещё не является просрочкой.

Работа выполняется в текущем каталоге, исходные незакоммиченные docs/assets сохраняются.
Фиксация коммитов и публикация в удалённый репозиторий в эту поставку не входят.
