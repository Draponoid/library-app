## Браузерная проверка

Сценарий выполнен автоматизированно на локальном сервере: вход библиотекаря → каталог четырёх книг → поиск «МАСТЕР» → выдача экземпляра → возврат → создание, изменение и удаление автора → отчёты → аудит → выход → регистрация читателя → вход → отсутствие служебных разделов → только собственные выдачи → просмотр на ширине 390 пикселей.

Результат: сценарий прошёл, необработанных ошибок JavaScript нет, горизонтального выхода страницы за мобильный экран нет. Снимки входа, каталога и мобильного интерфейса просмотрены визуально. Синтаксис JavaScript дополнительно проверен `node --check static/app.js`.

## Границы протокола

Протокол подтверждает перечисленные проверки учебной версии. Нагрузочные испытания большого фонда, независимый аудит безопасности и эксплуатация в публичной сети не проводились. Проверка приёмки преподавателем не подменяется этим протоколом.
